## 3. 流程一 · 全业务一条龙（推荐答辩）

**目标**：同一患者、一次看诊，走完 **检验 + 检查 + 处置 + 处方发药**，并在小程序查看报告。

### 3.1 业务时间线

```text
患者挂号缴费 → 医生叫号写病历 → 开检验/检查/处置/处方
    → 患者（或收费窗口）缴医嘱费
    → lab01 检验双签 → check01 检查双签 → disposal01 处置双签
    → 医生工作站查看全部结果
    → pharmacy01 发药
    → 小程序「我的报告 / 病历」
```

### 3.2 逐步操作

| 步 | 角色 | 页面 / 操作 | 预期 |
|----|------|-------------|------|
| 1 | 患者（小程序）或 `registrar01` | 挂号：内科 · 普通号 · `doctor01`；支付挂号费 ¥20 | `visit_state=1` 已挂号 |
| 2 | `doctor01` | `/doctor/workspace` → 候诊队列 **叫号** | `visit_state=2` 接诊中 |
| 3 | `doctor01` | 填写病历 → **保存**（文案见 §8 案例 A）→ 可选点 **AI 智能诊断** | 病历入库，RAG evidence 可见 |
| 4 | `doctor01` | **开检验**：`血常规` + `C反应蛋白`；**开检查**：`胸部 X 线`；**开处置**：`雾化吸入`；**AI 辅助处方** 确认：`阿莫西林胶囊` + `布洛芬缓释胶囊` | 各单 `status=10` 已开立 |
| 5 | 患者小程序 **我的费用 → 待缴** 或 `registrar01` **窗口收费** | 勾选全部待缴项并支付 | 医技/处方 `status=20`；处方进入待发药 |
| 6 | `lab01` | `/lis/queue` 筛 **已缴费** → **开始执行** → 报告预览 → **录入** → 保存 → **审阅** → **发布** | 检验 `status=40` |
| 7 | `check01` | `/pacs/queue` → **开始执行并进入影像 AI** → 上传/采三视图 → 保存快照 → 回队列 **录入**（可点 **重新采图** 回工作台）→ **审阅发布** | 检查 `status=40` |
| 8 | `disposal01` | `/disposal/queue` → **开始执行** → **录入** → **审阅发布** | 处置 `status=40` |
| 9 | `doctor01` | 工作站下方 **本次医嘱** 面板 → 查看检验/检查/处置报告 | 结构化报告 + 双签页脚 |
| 10 | `pharmacy01` | `/pharmacy/pending` 筛 **待发药** → **发药** | 处方 `status=30` 已发药 |
| 11 | 患者小程序 | **我的报告** / **电子病历** | 可见检验、检查、处置报告摘要 |

### 3.3 开单清单（流程一）

| 类型 | 项目编码 | 项目名称 | 参考价 | 开单目的（可填） |
|------|----------|----------|--------|------------------|
| 检验 | `INS-BLOOD` | 血常规 | ¥35 | 发热查因 |
| 检验 | `INS-CRP` | C 反应蛋白 | ¥45 | 感染指标 |
| 检查 | `CHK-CXR` | 胸部 X 线 | ¥90 | 排除肺部病变 |
| 处置 | `DIS-NEB` | 雾化吸入 | ¥35 | 缓解咽痛咳嗽 |
| 处方 | `DRG-001` | 阿莫西林胶囊 | — | 抗感染 |
| 处方 | `DRG-002` | 布洛芬缓释胶囊 | — | 退热镇痛 |

**处方用法示例（医生确认 AI 草稿后提交）**：

| 药品 | 单次 | 频次 | 天数 | 数量 | 嘱托 |
|------|------|------|------|------|------|
| 阿莫西林胶囊 0.25g | 2 粒 | 每日 3 次 | 7 | 2 盒 | 饭后服，青霉素过敏禁用 |
| 布洛芬缓释胶囊 0.3g | 1 粒 | 发热时 | 3 | 1 盒 | 不超过 3 次/日 |

### 3.4 医技录入 / 审阅文案（可直接复制）

**检验 · 医师意见**（仪器结果 execute 后由系统 seed 明细，录入时补医师意见）：

```text
白细胞 11.2×10^9/L，中性粒细胞比例 78%，CRP 18 mg/L。
符合急性细菌性感染可能，建议抗感染治疗，3 天后复诊或症状加重及时就诊。
```

**检查 · CT 所见 + 诊断印象 + 医师意见**：

```text
CT 所见
胸廓对称，双肺纹理稍增粗，肺野未见明显斑片状阴影，
心影大小形态正常，双侧膈面光整，肋膈角锐利。

诊断印象（正文，不含重复标题）
未见明确肺炎或胸腔积液征象，符合急性上呼吸道感染影像学表现。

检查医师意见
请结合临床与检验，必要时短期随访。
```

**处置 · 过程 + 结果**：

```text
【过程】
0.9% 氯化钠注射液 2 ml + 吸入用布地奈德混悬液 1 mg，
经雾化器吸入 15 分钟，患者配合良好。

【结果】
雾化过程顺利，诉咽痛稍缓解，无胸闷、气促，生命体征平稳。
```

## 7. 字段怎么分（写病历时 30 秒）

| 表单标签 | 库字段 | 填什么 |
|----------|--------|--------|
| 主诉 | `readme` | 患者**最不舒服什么 + 多久**（1～2 句） |
| 现病史 | `present` | 起病、加重/缓解、伴随症状、是否自行用药 |
| 现病治疗情况 | `presentTreat` | 来医院**之前**已做的治疗（无则填「未特殊治疗」） |
| 既往史 / 个人史 | `history` | 慢病、手术史等（无则填「无特殊」） |
| 过敏史 | `allergy` | **无则填「无」**（开处方前必看） |
| 体格检查 | `physique` | **T/P/R/BP** + 查体阳性/阴性体征 |
| 初步诊断 | `diagnosis` | 如「急性上呼吸道感染」 |
| 检查 / 检验建议 | `checkAdvice` / `inspectionAdvice` | 文字建议（可与 AI 开单配合） |

**记忆**：主诉 = 患者说；体格检查 = 医生查。
