# 清创换药处置原则
清创前应评估污染、异物、深部结构损伤、出血和神经血管状态，并核对破伤风免疫。复杂伤口、活动性出血、咬伤或重要结构损伤应转专科，不能由AI直接决定缝合或抗菌方案。

# 伤口缝合前复核
拟缝合伤口需评估受伤时间、污染程度、组织活性、异物及感染风险。严重污染、咬伤、穿刺伤或深部结构损伤不应机械按普通伤口即时闭合。

# 雾化吸入处置复核
雾化吸入应有明确适应证，并评估喘息程度、呼吸频率、血氧和既往反应。药物、剂量和频次必须由医生确认，呼吸状态不稳定者优先急症评估。

# 洗胃处置安全复核
洗胃仅适用于严格筛选的急性中毒情境，必须明确摄入物、时间、剂量、气道保护和禁忌。腐蚀性物质、挥发性烃类、气道未保护或消化道高风险时不得机械执行。

# 外伤固定与转运
疑似骨折或关节损伤应先评估远端血运、感觉运动、开放伤及严重畸形，再进行适当固定。固定后必须复查神经血管状态，开放性骨折或血运障碍需紧急转诊。

# 烧烫伤现场处置
烧烫伤应停止热源并采用适当流动清水冷却，避免冰敷、偏方和撕除粘连衣物。大面积、深度、特殊部位或吸入性损伤疑虑时应尽快转烧伤或急诊专科。

# 导尿处置复核
导尿应有明确指征，确认无尿道损伤线索并采用无菌操作，避免仅为方便常规留置。骨盆外伤伴尿道口出血、会阴血肿或明显置管阻力时应停止并请泌尿专科评估。

# 留观与转诊决策原则
病情诊断不明、生命体征波动、治疗反应不确定或存在进展风险时，应根据医院能力选择留观、专科会诊或转诊。转诊前需尽可能稳定患者并清楚交接病情、已做处理和风险。
